.detalhes-icon { transition: transform 0.2s cubic-bezier(0.2, 0, 0, 1); } .detalhes-header.open .detalhes-icon { transform: rotate(180deg); } @keyframes content-fade { from { opacity: 0; } to { opacity: 1; } } .detalhes-content.open { animation: content-fade 0.3s cubic-bezier(0, 0, 0.2, 1); }
Ajuste (v2): a primeira versão usava o mesmo fade-in com translateY(8px) dos outros reveals. Como o painel troca de display:none para flex instantaneamente (não dá pra animar display), o espaço já era reservado de uma vez, mas o conteúdo nascia 8px mais baixo — isso criava uma "divisão"/vão visível entre o header e o conteúdo por um instante, ficando pouco fluido. Trocamos por um fade só de opacidade (content-fade, sem transform), que faz o conteúdo nascer já na posição final, colado no header.

Ajuste (v2) — removido o fade-in de .pdp-card e o slide-up de .pdp-sidebar: a v1 tinha .pdp-card (fade-in) envolvendo a descrição e .pdp-sidebar (slide-up) envolvendo o título do produto — só que .pdp-benefits já vive dentro dos dois (flutuante dentro do card no mobile, dentro da sidebar no desktop) e sempre teve sua própria animação (content-fade). Duas animações de opacidade sobrepostas, com easings diferentes, rodando ao mesmo tempo no mesmo trecho de tela — resultava num flicker estranho bem visível no título e na descrição. A correção foi remover a animação dos dois containers "de fora" e deixar só a animação própria de .pdp-benefits, que segue funcionando normalmente.

2️⃣ Hover no header do acordeão (Termos)

.termos-header:hover — sombra sutil, mesmo padrão do Checkout Box (ver #c-hover)

Efeito
box-shadow 0 8px 16px rgba(0,0,0,0.12)
Duração
200ms standard
Onde

Condições da oferta e termo de adesão ⌄
.termos-header { transition: box-shadow 0.2s cubic-bezier(0.2, 0, 0, 1); } @media (hover: hover) { .termos-header:hover { box-shadow: 0 8px 16px rgba(0, 0, 0, 0.12); } }
@media (hover: hover): em telas touch não existe mouse pra "sair" do elemento depois do tap, então um :hover comum pode ficar grudado — a sombra vira uma linha/mancha cinza permanente sob o header. Envolver a regra em @media (hover: hover) garante que ela só se aplica em dispositivos com hover de verdade (mouse), nunca em touch. Mesma correção aplicada no header "Ver detalhes do produto" do Checkout Box e no botão "Ver grade completa" (item 4 abaixo), nas duas telas.
